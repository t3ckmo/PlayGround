# PlayGround

## BLACKWATER — Chapter I: The House That Waits

A short first-person survival-horror chapter built to run in the browser with no build step. The road is gone, the lights are dead, and something wearing a sewn-shut mask is walking the halls.

**Objective:** find two ceramic fuses, restore the breaker in the hall, descend into the cellar for the iron key, and escape through the front door.

### Play

Serve the folder with any static file server and open `index.html`.

```bash
python3 -m http.server 3002
```

Then visit `http://localhost:3002`.

### Controls

| Action | Keyboard / mouse | Touch |
| --- | --- | --- |
| Move | `WASD` / arrow keys | Left-thumb joystick |
| Look | Mouse | Drag on the right side |
| Interact | `E` | Hand button |
| Fire | Left click / `Space` | Fire button |
| Run | `Shift` | Double-chevron button |
| Flashlight | `F` | Torch button |
| Reload | `R` | — |
| Pause | `Esc` | Pause button |

Headphones are recommended. The game uses procedural Web Audio for its soundscape and procedurally generated canvas textures for the world, so there are no external art or audio assets.
